# 为什么我要做新博客
我最早的博客是采用的hexo，原因无他因为上手很简单，也不需要我自己去搞什么杂七杂八的东西。  
但是有一天我重装系统的时候发现hexo还是有几个小问题：  
1. 不方便迁移设备
2. 我不能随心所欲的在任何一台设备上记笔记  

~~再加上本人也有一部分的赛博受虐癖，所以决定重新制作一个新版~~

# 技术栈  
整个博客其实没有什么特别复杂的技术

主体使用 Next.js，并结合 Route Handlers 提供 API，再通过 SSG 生成静态页面。这样既不需要 SSR，也能获得不错的 SEO 表现

~~至于最后实际效果怎么样……好像 SSR 也挺不错，而且仔细想想和 Hexo 的原理其实差别也没有想象中那么大~~

评论系统依然选择了 Gitalk，主要还是因为已经用了很久，习惯了。

博客里的「作者与你的位置」功能，则是通过 iOS Shortcuts + Route Handlers + Redis 存储作者当前位置，再结合浏览器定位计算访客与我的直线距离以及时区差

~~没错，我的手机会同步自己的位置。哇，快来盒我~~

# 风格
风格上我参考了 GTMC 早期 Beta 时期的设计。（我真的不喜欢现在 Release / 后期 Beta 的样式）

另外，最近我特别喜欢「卫星」这个概念。山茶花的《Satellite》我已经循环了不下百遍

我的个人主页采用的是「黑洞 + 数据面板 + 卫星」的组合，而这次的博客依然保留了卫星这一元素，只不过更加偏向 System 的概念，例如卫星轨道、文件、系统面板等，希望整个页面看起来更像一个正在运行的系统
